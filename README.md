# 🎵 MeloGroove — Online Music Player for Android

یک کلاینت مدرن، سریع و زیبای پخش موسیقی آنلاین برای اندروید که با **Kotlin** و **Jetpack Compose** بر پایه معماری تمیز (Clean MVVM) پیاده‌سازی شده است.

---

## ✨ ویژگی‌های برجسته (Key Features)

- 🇮🇷 **انتخاب هوشمند کشور و آنبوردینگ:** پرسش اولیه از کاربر برای انتخاب کشور مورد علاقه جهت گوش دادن به موسیقی (با اولویت و جایگاه ویژه برای **ایران** 🇮🇷 و همچنین برترین کشورهای جهان نظیر اسپانیا، ایالات متحده، بریتانیا، فرانسه، آلمان و ترکیه).
- 🔄 **فید صفحه اصلی پویا:** به‌روزرسانی خودکار ترندها، پیشنهادات، خوانندگان برتر و اولویت‌های جستجو بر اساس کشور انتخابی با قابلیت تغییر آنی در هر زمان.
- 🖤 **طراحی تم تاریک مخصوص نمایشگرهای OLED:** زمینه مشکی عمیق (`#090C10`) برای بیشترین صرفه‌جویی در مصرف باتری همراه با رنگ‌های نئونی طلایی و نارنجی گرم (`#FFB800` و `#FF7A00`).
- 📻 **پلیر پیشرفته با گرامافون دوار (Vinyl Record):**
  - انیمیشن چرخش صفحه وینیل به هنگام پخش.
  - نوار لغزنده پیشرفت آهنگ (Seek Slider) با نمایش دقیق زمان سپری‌شده و کل زمان.
  - دکمه‌های کنترل نئونی، حالت‌های تکرار، پخش تصادفی (Shuffle) و افزودن سریع به پلی‌لیست.
- 🚗 **حالت رانندگی ایمن (Driving Mode):** رابط کاربری با کنتراست حداکثری، دکمه‌های بسیار بزرگ لمسی (۷۶dp+) و دسترسی به موزیک‌های جاده، انرژی و آرامش سفر بدون حواس‌پرتی.
- 🔍 **جستجوی پیشرفته چندمعیاره:** جستجوی بلادرنگ بر اساس نام آهنگ، خواننده، آلبوم، سال تولید و سبک موسیقی (پاپ، سنتی، راک، الکترونیک و...).
- 📚 **کتابخانه و مدیریت پلی‌لیست‌ها:**
  - سیستم علاقه‌مندی‌ها (Favorites) با ذخیره‌سازی پایدار محلی در دیتابیس Room.
  - ساخت پوشه‌ها و پلی‌لیست‌های دلخواه (مانند «پلی‌لیست شاد»، «جاده»، «شبانه»).
  - ثبت خودکار تاریخچه شنیدن (Listening History) با امکان پاکسازی.
- 🎧 **پخش در پس‌زمینه و کنترل‌های سیستمی:**
  - یکپارچه‌سازی کامل با Media3 و ExoPlayer و MediaSession.
  - کنترل‌های پخش روی صفحه قفل (Lockscreen) و نوار اعلان‌ها.
  - پشتیبانی از دکمه‌های هدفون بلوتوثی و مدیریت قطعی صدا.
  - انتخابگر ۳ سطح کیفیت استریم صوتی (کیفیت بالا ۳۲۰kbps، استاندارد ۱۹۲kbps، کاهش مصرف دیتا ۹۶kbps).

## 🛠️ ساختار معماری و تکنولوژی‌ها

- **زبان:** Kotlin
- **رابط کاربری:** Jetpack Compose + Material Design 3 (M3)
- **موتور پخش صدا:** Android Media3 ExoPlayer + MediaSessionService
- **دیتابیس محلی:** Android Room Persistence Library + Flow
- **لایبرری‌های شبکه:** Retrofit 2 + OkHttp 3 + Moshi
- **لود تصاویر آلبوم:** Coil Compose
- **مدیریت وضعیت:** ViewModel + StateFlow

## 🚀 نحوه خروجی گرفتن و نصب فایل APK

### ۱. بیلد پروژه از طریق خط فرمان:
```bash
gradle :app:assembleDebug
```

فایل APK تولید شده در مسیر زیر قرار می‌گیرد:
```
app/build/outputs/apk/debug/app-debug.apk
```

### ۲. نصب مستقیم روی گوشی اندروید:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
