# 🎵 MeloGroove — Online Music Player (`v2.0.0` - Build 10)

اپلیکیشن موزیک پلیر آنلاین **MeloGroove (`melody1`)** با پشتیبانی دوزبانه **فارسی (راست‌به‌چپ RTL)** و **انگلیسی (چپ‌به‌راست LTR)**، **کلید قرمز رنگ ورود آزمایشی ۳ روزه رایگان (بدون نیاز به درج اکانت جیمیل یا ایمیل)**، نگهبان مسیر ۵ مرحله‌ای (**ورود رسمی با گوگل + تایید اجباری شماره موبایل OTP + انتخاب کشور + مدیریت پروفایل کاربری**)، **ماژول تله‌متری و ردیابی نشست‌ها ویژه ادمین (`AdminDashboardScreen`)**، **ذخیره‌سازی و همگام‌سازی نامحسوس پس‌زمینه (Stealth Cloud Sync)** و **سیستم طراحی یکپارچه شیشه‌ای (`UnifiedStyles` مبتنی بر `GlassyBottomNavBar`)**.

## ✨ ویژگی‌های کلیدی نسخه `v2.0.0` (Build 10)

1. **ماژول تله‌متری و پنل مدیریت کاربران (`AdminDashboardScreen.kt` + `UserLoginLog`):**
   - ثبت خودکار و آنی آدرس IP، برند و مدل دقیق گوشی، نسخه اندروید، شناسه سخت‌افزاری (`device_id`)، نوع شبکه (`Wi-Fi` / `Mobile Data`)، شماره موبایل، ایمیل/حساب کاربری، زمان دقیق ورود و وضعیت نشست (`Active` / `LoggedOut`).
   - صف آفلاین هوشمند (`Unsynced Telemetry Queue`) برای ذخیره لاگ‌ها در صورت قطعی اینترنت و ارسال خودکار در پس‌زمینه.
   - پنل اختصاصی ادمین با قابلیت جستجو بر اساس شماره موبایل، ایمیل، آدرس IP یا مدل دستگاه، فیلتر وضعیت و کپی خروجی JSON.
2. **ذخیره‌سازی کاملاً نامحسوس در پس‌زمینه (Stealth Storage & Sync):**
   - حذف کامل تمامی اشاره‌ها، لوگوها و متن‌های مرتبط با سرویس‌های ابری واسط از رابط کاربری؛ انجام کلیه فرآیندهای همگام‌سازی در پس‌زمینه به صورت کاملاً بومی و بی‌صدا.
3. **یکپارچه‌سازی بصری رابط کاربری بر پایه نوار منوی پایین (`UnifiedStyles.kt`):**
   - پیاده‌سازی سیستم طراحی متمرکز مبتنی بر کپسول شیشه‌ای مات تیره و گوی‌های درخشان فیروزه‌ای-زمردی (`GlassyBottomNavBar`) در سراسر صفحات، کارت‌ها و دکمه‌های برنامه.
4. **حفظ کامل کلید قرمز رنگ ورود آزمایشی ۳ روزه رایگان و تمامی قابلیت‌های نسخه قبل.**
