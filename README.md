# 🎵 MeloGroove — Online Music Player (`v1.6.0` - Build 6)

اپلیکیشن موزیک پلیر آنلاین **MeloGroove** با پشتیبانی دوزبانه **فارسی (راست‌به‌چپ RTL)** و **انگلیسی (چپ‌به‌راست LTR)**، پخش کامل آهنگ بدون نیاز به فیلترشکن برای کاربران ایران، سیستم ثبت‌نام و ورود با ایمیل، مالکیت ۱۰۰٪ کاورهای خوانندگان، تفکیک کاتالوگ بر اساس کشور، سرویس پخش پایدار در پس‌زمینه و کنترل کامل از صفحه قفل و نوار اعلان.

## ✨ مهم‌ترین ویژگی‌ها و اصلاحات نسخه `v1.6.0` (Build 6)

1. **تطابق ۱۰۰٪ کاور و تصویر خواننده با مالک واقعی (`ArtworkResolver` — رفع `N-01`, `U-01`, `U-02`, `U-07`):**
   - هر کاور فقط برای مالک اصلی خود (`ownerArtistId == artistId`) نمایش داده می‌شود و برای ترک‌های فاقد کاور اختصاصی، آواتار مونوگرام اختصاصی با گرادیان دو رنگ نمایش داده می‌شود.
2. **حذف تصاویر خوانندگان از کارت‌های مود و ژانر (`N-02`):**
   - استفاده از نشان گرافیکی و گرادیان اختصاصی هر مود در `ModernMoodCard`.
3. **موتور گروه‌بندی پویا با سقف تنوع خواننده (`GroupEngine` — رفع `N-03`, `U-03`):**
   - اعمال `perArtistCap = 1` در کاروسل «بروزترین انتشارها» برای جلوگیری از تکرار پشت‌سرهم یک خواننده.
4. **کاتالوگ ساختیافته JSON در Assets (`CatalogDataSource` — رفع `N-04`):**
   - نگهداری کاتالوگ در `assets/catalog/artists.json`، `groups.json` و `tracks.json`.
5. **شناسه ۶۴ بیتی قطعی (`IdGenerator`) و مهاجرت غیراهدامی دیتابیس Room به نسخه ۴ (`MIGRATION_3_4` — رفع `N-06`, `N-07`, `N-14`).**
6. **سیستم کامل ثبت‌نام و ورود با ایمیل بدون نیاز به فیلترشکن (`AuthRepository` و `AuthScreen` — بخش ۶).**
7. **حذف تاریخچه نسخه‌ها از صفحه تنظیمات داخل برنامه طبق درخواست کاربر.**
