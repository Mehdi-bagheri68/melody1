# 🎵 MeloGroove — Online Music Player (`v1.5.0` - Build 5)

اپلیکیشن موزیک پلیر آنلاین **MeloGroove** با پشتیبانی دوزبانه **فارسی (راست‌به‌چپ RTL)** و **انگلیسی (چپ‌به‌راست LTR)**، پخش کامل آهنگ بدون نیاز به فیلترشکن برای کاربران ایران، کاورهای آفلاین، تفکیک کاتالوگ بر اساس کشور، سرویس پخش پایدار در پس‌زمینه و کنترل کامل از صفحه قفل و نوار اعلان.

## ✨ مهم‌ترین ویژگی‌ها و اصلاحات نسخه `v1.5.0` (Build 5)

1. **صحت ۱۰۰٪ منبع پخش (`SourceResolver` — رفع `BUG-01`):**
   - هرگز در صورت خطا یا نبود لینک، فایل صوتی آهنگ دیگری به جای آهنگ انتخاب‌شده پخش نمی‌شود.
2. **طبقه‌بندی هوشمند خطاها و تلاش مجدد سقف‌دار (`Bounded Exponential Backoff` — رفع `BUG-02`):**
   - تفکیک خطاهای دائمی (`404/403/Format`) از خطاهای موقت شبکه (`Timeout/5xx`) با حداکثر ۶ تلاش خودکار تصاعدی + دکمه «تلاش مجدد دستی».
3. **اعتبارسنجی دقیق `MediaItem` پیش از `Seek` و نمایش زمان واقعی (`BUG-03` و `BUG-05`):**
   - بررسی تطابق شناسه و URI قطعه پیش از پرش زمانی و نمایش `"--:--"` برای ترک‌های وب تا زمان دریافت مدت واقعی از `ExoPlayer`.
4. **پارسر ایزوله HTML با تشخیص صفحات ضدربات (`MusicsFaHtmlParser` — رفع `BUG-04`):**
   - تشخیص صفحات کپچا/Cloudflare، پاکسازی HTML Entities و ثبت سلامت هاست‌ها.
5. **کش جستجوی ایمن (`Mutex + TTL`) و لغو خودکار درخواست‌های قبلی (`BUG-06`، `BUG-07`، `BUG-08`):**
   - همگام‌سازی زنده وضعیت علاقه‌مندی‌ها (`favoriteIds`) و لغو `Job`های قبلی هنگام تغییر سریع کشور یا مود.
6. **سوییچ واقعی کیفیت استریم (`320kbps` / `128kbps`) و سوییچ حالت بدون فیلترشکن (`BUG-09` و `BUG-10`).**
7. **اصلاحات جامع UI/UX (`UI-01` تا `UI-14`):**
   - ارتفاع تطبیقی کارت‌های مود، کلیدهای پایدار در لیست‌ها، پنل فیلتر جمع‌شونده در جستجو، دیالوگ تأیید پیش از حذف پلی‌لیست/تاریخچه، توقف چرخش صفحه گرامافون در حالت مکث/بافرینگ و پشتیبانی کامل Bidi برای متون ترکیبی فارسی و انگلیسی.
